# Nebula Frontier V12 – Uridium
- Zweite Spielwährung **Uridium** (violette Premium-Währung).
- 0 Uridium bei neuen Accounts, alte Accounts werden automatisch ergänzt.
- Kostenlos erspielbar: +1 je NPC auf X1–X4, +2 je NPC auf X5–X8, +80 für X8-Boss, +30 für die erste abgeschlossene Quest.
- Neue Shop-Kategorie Uridium mit vier kaufbaren Produkten.
- Käufe und Währungsabzug erfolgen ausschließlich auf dem Server.
- Keine Echtgeldzahlungen, keine Zahlungsintegration.
- **Wichtig:** Die bisherige Render-JSON-Speicherung ist noch nicht dauerhaft. Supabase steht weiterhin aus.
