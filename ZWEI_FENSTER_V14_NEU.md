# Nebula Frontier V14 – Zwei Fenster gleichzeitig

**Fenster 1: Kommandozentrale** – Pilotenprofil, Shop-Kategorien, Inventar, Credits, Uridium, Schiffe, Drohnen und Upgrades.

**Fenster 2: Spiel** – die normale Canvas-Welt, PvP, NPCs, Radar, Chat und FPS/Ping.

Ablauf:
1. Wie gewohnt im Spiel anmelden.
2. „SPIEL + ZENTRALE ÖFFNEN“ anklicken.
3. Das Spielfenster bleibt geöffnet und läuft weiter; die Kommandozentrale erscheint in einem zweiten Browserfenster.
4. Auf dem Handy werden die Fenster ggf. als zwei Tabs dargestellt (Browser-/Betriebssystem-bedingt).

Die Kommandozentrale benutzt **dieselbe Anmeldung und dieselbe WebSocket-Verbindung** über eine direkte, gleich-originige Fensterbrücke. Dadurch werden keine zweiten Spieler-Sessions erzeugt. Das Hauptfenster muss offen bleiben. Der Browser muss Pop-ups erlauben.

Hinweis: Browser drosseln inaktive Tabs unter Umständen; zwei gleichzeitig sichtbare Fenster funktionieren auf Desktop am besten. Auf Mobilgeräten können Tabs nicht immer nebeneinander sichtbar sein.
