# V23 – Bonusboxen

- Auf jeder Fraktions- und Neutralmap erscheinen neun Bonusboxen.
- Anklicken/Antippen in maximal 90 Spieleinheiten Entfernung sammelt die Box ein. Bei größerer Entfernung wird das Schiff zur Box geschickt; danach erneut antippen.
- Zufälliger kleiner Inhalt: Credits (10–50), Uridium (1–5), X1/X2/X3-Lasermunition (3–40), PLT-2020/2023/2026-Raketen (1–4).
- Eine eingesammelte Box verschwindet für alle und wird nach 18 Sekunden an neuer Stelle ersetzt.
- Inhalt wird serverseitig ausgelost und direkt im Spielerprofil gespeichert.
- Bonusboxen erscheinen als leuchtende türkisfarbene Diamanten und als Punkte auf der Minimap.
