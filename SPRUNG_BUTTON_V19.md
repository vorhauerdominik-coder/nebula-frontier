# Nebula Frontier V19 – Achteckiger Sprung-Button

- Sobald dein Schiff näher als 165 Welteinheiten an ein Sprungportal fliegt, erscheint unten rechts ein großer achteckiger Button mit leuchtendem Portal-Symbol in der Mitte.
- Beschriftung zeigt den Zielsektor. Ein Klick bzw. Touch löst den Sprung aus.
- Bei mehreren Portalen in Reichweite wird das nächstgelegene gewählt.
- Außerhalb der Reichweite wird der Button automatisch ausgeblendet.
- Taste E funktioniert weiterhin. Der Server kontrolliert Portal-ID und Distanz unverändert; kein Teleport-Cheat.
- Auf Smartphones ist der Button kleiner und per Touch bedienbar.
- Beim Öffnen des Sternensystems wird der Sprung-Button ausgeblendet.

Installation: ZIP-Inhalt ins GitHub-Repository kopieren, Render deployen lassen. Bitte Portal-Klicks im Browser testen.
